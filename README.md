# Chess Game Vision

Шахматный тренажёр для отработки шахматного зрения (поиска шахов и взятий) с последующей партией против движка **Stockfish 18**.

## Основные возможности

1. **Двухфазный цикл каждого хода**:
   - **Фаза А (`🔍 Поиск шахов и взятий`)**: перед выполнением собственного хода ученик должен найти все доступные шахи и взятия (как за себя, так и за соперника). Пробы ходов проверяются и автоматически возвращаются на место.
   - **Фаза B (`♟ Ваш ход`)**: после завершения поиска (или по кнопке «Сделать ход →») ученик делает реальный ход белыми, на который сразу отвечает Stockfish.
2. **Расчёт точности по формуле Lichess**:
   - Оценка позиции переводится в вероятность выигрыша ($W = \frac{100}{1 + e^{-0.00368208 \cdot \text{cp}}}$).
   - Точность каждого хода и средняя точность за партию вычисляются по оригинальной формуле Lichess.
3. **Автоматический отчёт тренеру**:
   - Отправка детальной статистики через Formspree: процент найденных шахов/взятий, точность игры по Lichess, среднее время поиска, PGN с заполненными метаданными (`[White]`, `[Black]`, `[Result]`).
4. **Сохранение сессии**:
   - Автосохранение текущей партии и настроек в `localStorage`. Возможность продолжить незаконченную партию после перезагрузки.
5. **Современный UI**:
   - Текстурная доска `brown` на базе **Chessground** с SVG-фигурами.
   - Адаптивная верстка, таймеры с инкрементом, звуки и анимации.

## Стек технологий

- **Vite 8** + **TypeScript 7**
- **Tailwind CSS v4**
- **Chessground 9**
- **Chess.js 1.4**
- **Stockfish 18** (WebWorker / WebAssembly)

## Запуск проекта

### Установка зависимостей:
```bash
npm install
```

### Запуск в режиме разработки:
```bash
npm run dev
```

### Сборка для продакшена:
```bash
npm run build
```

### Предпросмотр сборки:
```bash
npm run preview
```
